# Security policy

UdpTcpListener reads raw network traffic and runs with elevated rights, so we take security issues seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private
[security advisory form](https://github.com/shaxboz1011/UdpTcpListener/security/advisories/new) instead.
Include the version, OS, steps to reproduce and, if possible, a capture file that triggers the problem (with no private data).

We aim to acknowledge reports within 7 days.

## Supported versions

Only the latest release receives fixes. The app updates itself, so most users are on the latest version.
